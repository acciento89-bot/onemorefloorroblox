## Assets used by the actual player

Four editable original model prefabs are saved under `Assets/Models/SculptedConcept`: AdventureBoy, OrnateCarriage, CarvedBalcony and GrandLobby. Boy, carriage and balcony use their `Geometry-v2.asset` files; GrandLobby uses `GrandLobbyGeometry-v3.asset` after the actual lobby comparison exposed a short foreground floor. The initial geometry files are retained as earlier authoring snapshots outside Resources. The Resources/Models/ConceptArtSet catalogue references the current prefabs, and runtime builders instantiate them for gameplay and actual menu previews. The lobby catalogue supplies only its architecture child because runtime already composes a carriage and passenger.

Instances own mesh copies and mutable materials; selected outfits cannot recolor artist source assets or another avatar. Architectural instances bind to the existing owning palette. Source meshes and the shared generated atlas remain persistent. Existing visual batching, disposal, collision and camera authority are retained.

The boy now has twelve curved face height sections, integrated ear contours, sixteen-sided rounded nose, smoother smile/brows, additional front/rear hair strands, a dark-green hood sharing the chosen jacket material and a textured garment/hair atlas. Presentation scale is 1.10 rather than 1.35, without changing movement physics. Actual mesh budget is 5,760 vertices / 9,962 triangles / 31 default renderers / 8 materials. The runner budget log counts **owned generated** textures as zero with the atlas present; one persistent shared imported atlas is actually sampled by clothing/hair materials.

Original balcony stone flutes and curved capitals use an existing batch/material. The marble foreground now extends toward the authoring camera so the lobby bottom shows its modeled room floor rather than falling through to the sky backdrop. Current architecture fixture has 29,049 vertices / 12 materials / 2 main textures. Cabin roof subdivisions are reallocated while retaining its silhouette: 7,719 vertices / 32 raw renderers. Two bounded warm point lights follow the occupied and next doorway. Child menus now use an opaque default UI backdrop, hiding the gameplay world and action behind settings/style/shop/daily/achievements. Home retains its own full atrium and checkpoint/bank decisions retain tower context; Back/resume/input authority is unchanged. Existing cabin light, URP warm volume, bloom, orthographic focus, gold/glass/ivory nine-slice UI, TMP fonts and distinct real city cards remain active. Portrait lobby focus was raised to improve carriage composition.

## Native Editor work

Unity 6000.6.4f1 was opened as an actual Mac GUI process, after the user confirmed the Unity terms themselves. The native One More Floor / Art Studio window exposes the original model prefabs, Scene View editing and GPU close-ups. The saved ConceptArtStudio scene is an authoring scene, outside the enabled Main build scene. Untitled startup contents were preserved in PreservedStartup instead of discarded.

The editor-only command file is a bounded local action bridge; it is not a Unity MCP provider or network server. Shader passes are compiled synchronously for first captures so cold asynchronous variants do not omit masonry/foliage. A readonly review found that reopening the authoring scene could overwrite saved edits; the loader now opens the existing saved scene. A real native close/reopen test confirms saved root position and active state survive, then removes its own probe. Capture cameras and lamps are transient; artist model instances are retained.

Native startup serialized URP debug input axes, color-temperature support, PackageManager/URP settings and IAP BillingMode. Existing ProjectBootstrap also aligned auto-rotation with the current portrait/both-landscape runtime contract and disabled upside-down portrait. No product version, enabled build scene, provider credentials or store transaction was changed.
